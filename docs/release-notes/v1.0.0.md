# Blink Shop v1.0.0 版本说明

Blink Shop 是对 xzxg-shop 的功能等价复刻：Go API、React 管理端 / 商家端 Web、Java 原生 Android 用户端，带 AI 导购（规则可独立运行，模型可选）。
本版本完成 `docs/09-granular-development-plan.md` 的全部功能包（0.1–10.2）。验收记录见 [`docs/11-acceptance-record.md`](../11-acceptance-record.md)。

## 功能

**用户（Android）**
- 注册登录、商品列表与筛选、商品详情（SKU、库存、属性、评价、促销）。
- 购物车：服务端试算、按店铺拆单、自动选最优券。
- 结算：幂等。断网或结果未知时冻结上次提交，只能原样重发，不会重复下单；被杀进程后可以从购物车横幅恢复。
- 模拟支付、确认收货、评价（草稿恢复）、取消订单、领券。
- AI 导购聊天：
  - 流式回答，思考步骤，商品卡、对比、引用、购物车、订单、券等结构化块；
  - 追问加购、结算、支付；历史会话（置顶、重命名、删除）。
- 图片附件（拍照 / 相册）按图找同款；语音输入（实时转写）与朗读；断网、拒权、服务未配置都有提示和恢复。

**商家（Web）**
- 本店商品增删改与上下架（风控商品不可操作）。
- 知识资料：常见问题、网页采集（SSRF 防护）、切片。
- 订单发货、促销规则、评价回复。

**平台管理员（Web）**
- 账号 / 店铺 / 商品 / 订单 / 促销 / 评价治理：状态机、原因必填、操作审计。
- 风控概览与风险词。
- 应用配置：密钥掩码，可存 Nacos。
- Prompt 管理：草稿、发布、回滚，带版本冲突保护。
- 调试观测：运行列表、时间线、汇总、所用 Prompt 版本。
- 质量评测：套件、报告、失败样例、单条试跑、向量状态。

**AI 导购**
- 规则规划 + 工具白名单，任何写操作只走工具层校验，不能凭模型输出直接写。
- 可选模型规划 / ReAct / 重排 / 摘要，失败退回规则。
- RAG 引用只引用真实分块；商品搜索支持预算、品牌、排除和冲突。
- 会话记忆；风险词前置拦截；轨迹全程脱敏。

## 运维与安全

- 生产配置校验：拒绝默认密码、宽松 CORS、示例密钥、mock 语音、明文语音地址、弱指标令牌。
- `/metrics`（Prometheus）、18 条告警规则与 SLO。
- 熔断（模型、Embedding、Milvus）；Nacos 熔断与启动预算；摘流关闭；连接池可配。
- 镜像 `backend/Dockerfile`（distroless、非 root，带 `/migrate`）；应用层部署 `deployments/app/`（nginx 静态站点 + 反代）。
- 运维手册 `deployments/RUNBOOK.md`（发布、备份恢复、回滚、故障处理）。
- 发布前复核 `docs/10-release-readiness.md`（压测、演练、扫描、风险清单）。
- CI 共 6 个任务：Backend、Web、Android、Web E2E、OpenAPI & Compose、Security & Monitoring。

## 升级 / 首次部署

1. 按 `deployments/app/app.env.example` 准备生产配置（专用数据库账号、明确的 CORS、非默认对象存储凭据、`METRICS_TOKEN`、`SHUTDOWN_DRAIN=5s`）。
2. 备份数据库，然后执行迁移：`docker run --rm --env-file app.env --entrypoint /migrate blink-shop-api:1.0.0 -apply`。
3. 滚动部署 API，负载均衡就绪检查用 `/api/v1/ready`；需要向量检索 / 图搜时运行 `cmd/vectorindex` 建索引。
4. 回滚：部署上一个镜像，不回滚数据库，保持 `RUN_MIGRATIONS=false`（见运维手册）。

## 已知限制

- 同一 SKU 的结算串行（行锁），爆款抢购吞吐受单个事务时长限制（风险 R1）。
- 商品关键词搜索用 `LIKE`，商品量很大时需要全文索引或搜索引擎（R2）。
- 本地开发用 Compose 镜像有已知漏洞，只用于本地（R3）。
- 验收在 Android 模拟器（API 35）上进行，没有真机，真机验收待补（见验收记录）。
- 模型、Embedding、语音的真实供应商在验收中用假服务 / mock 代替，接入真实供应商时需要按运维手册复测。
