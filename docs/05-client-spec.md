# 客户端规格

## React Web（商家与管理员）

登录后按 role 路由，路由守卫与后端鉴权双重存在。通用组件：加载/空态/错误重试、分页表格、状态标签、确认对话框、金额与时间格式化、文件上传。请求 client 自动注入 token，401 清会话并回登录；不可把 token 写进 URL。

| 页面 | 必备交互 |
| --- | --- |
| 登录 | 用户名/密码校验、登录失败提示、按角色进入默认工作台 |
| 商品巡检/详情 | 分类与关键词筛选、商品卡、SKU/库存/属性/评价/促销展示 |
| 商家工作台 | 仅本商家商品增改删、知识文档与采集、订单发货、促销配置、评价回复 |
| 平台管理 | 账号/商家/商品/订单/促销/评价分页治理，风险状态二次确认 |
| Prompt 管理 | 历史版本、编辑草稿、发布、当前 active 显示；密钥不可见 |
| 调试观测 | run 列表和时间线：规划、工具、检索、输出、失败、耗时 |
| 质量评测 | 数据集、工具套件、报告、通过率和失败样例；向量索引状态 |

## 原生 Android（用户端）

Java 包名 `com.blink.shop`。用 OkHttp 管理请求、SSE 与 bearer token；SharedPreferences 保存会话（安全存储可作为增强）。页面：登录注册、商品列表/筛选、商品详情、聊天、购物车、结算、订单、优惠券、账户资料、设置/帮助。聊天支持历史抽屉、图片选择/拍照、流式 markdown、商品/比较块点击跳转、取消生成、TTS 播放。商品/购物车/订单页展示可关闭的 AI 浮窗建议；点击带入聊天。

运行时请求相机、录音、媒体权限并处理拒绝。Debug 允许在高级设置改 API base；Release 禁止该入口，base URL 从安全构建配置注入。网络错误、离线、SSE 中断、TTS/STT 未配置都有用户可理解的提示和重试，不崩溃。

## 视觉与可访问性

品牌可自行设计，不复用上游图标/文案。触控目标不小于 44dp，颜色不是唯一状态表达，图片有 content description，金额/时间本地化。手机窄屏、长商品名、空数据、加载中和权限拒绝都需要验收截图。
